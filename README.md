# Memory Core v1.0

スマホで使える個人用の外部記憶庫。静的Webアプリで、GitHub Pagesに公開できます。

## v1でできること
- 記録の作成・編集・削除
- カテゴリと状態の管理（確定 / 検討中 / 保留 / 却下 / 未確認）
- タイトル、内容、タグで検索
- JSONバックアップと復元（同じIDの記録は更新）
- Markdownエクスポート
- スマホ向けダークUI

## 使い方
1. GitHubで新しいリポジトリを作成
2. このZIPを解凍してファイルをアップロード
3. Repository Settings → Pages
4. Build and deploymentでDeploy from a branchを選択
5. Branchを `main`、Folderを `/ (root)` にしてSave
6. PagesのURLを開く

## データ保存について（重要）
このv1は、記録を**使っているブラウザのlocalStorage**に保存します。GitHub Pages上にデータが自動保存されるわけではなく、他の端末・ブラウザと自動同期もされません。
- 定期的に「バックアップ」からJSONを保存してください。
- 端末変更時はJSONを読み込んで復元できます。
- ブラウザのサイトデータを消すと記録が消える場合があります。
- 記録に個人情報・パスワード・秘密情報は入れないでください。
